# Responsive Portfolio Website 🌐

A responsive and elegant personal portfolio website built with HTML, CSS, JavaScript, and Bootstrap. This project is ideal for showcasing your skills, projects, and contact information in a professional and modern format.

---

## 📌 Features

- ✅ Fully responsive layout for mobile, tablet, and desktop
- ✅ Sticky navigation bar with smooth scrolling
- ✅ Hamburger menu for mobile navigation
- ✅ Scroll-to-top button
- ✅ Animated transitions
- ✅ Personal introduction, skills, and project showcase
- ✅ Contact section with location, email, and phone number
- ✅ Font Awesome & Remix Icons integration

---

## 💻 Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- **Bootstrap 5**
- **Font Awesome**
- **Remix Icons**
- **Google Fonts**
